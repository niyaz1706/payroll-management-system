# Payroll Management System — Backend

Backend service for a full-stack Payroll Management System built with NestJS, TypeScript, and MongoDB.

## Tech Stack

- NestJS
- TypeScript
- MongoDB
- Mongoose
- REST API
- Swagger / OpenAPI
- JWT Authentication
- Role-Based Access Control (RBAC)
- Class Validator
- Helmet
